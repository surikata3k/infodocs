# Tmux

| Action | Command |
|---|---|
| New session | `tmux new` |
| List sessions | `tmux ls` |
| Attach to the latest session | `tmux attach` |
| Attach to session 0 | `tmux attach -t 0` |
| Detach from the session | ++ctrl+b++ then ++d++ |

!!! tip "Cheat sheet"
    Full list of shortcuts: [tmuxcheatsheet.com](https://tmuxcheatsheet.com/)

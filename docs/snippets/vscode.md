# VS Code

| Action | Keys |
|---|---|
| Command palette | ++ctrl+shift+p++ |
| Open file by name | ++ctrl+p++ |
| Show / hide the panel (terminal) | ++ctrl+j++ |
| Show / hide the sidebar | ++ctrl+b++ |
| Comment / uncomment line | ++ctrl+slash++ |
| Move line up / down | ++alt+arrow-up++ / ++alt+arrow-down++ |
| Duplicate line | ++shift+alt+arrow-down++ |
| Delete line | ++ctrl+shift+k++ |
| Select next occurrence | ++ctrl+d++ |
| Add a cursor | ++alt++ + click |
| Format document | ++shift+alt+f++ |
| Rename symbol | ++f2++ |
| Go to line | ++ctrl+g++ |

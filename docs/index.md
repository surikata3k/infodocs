# IT-Hub

A personal collection of IT notes I keep while working and teaching: commands I use often, configuration examples, short tutorials and cheat sheets. Everything is written to be copied and used directly, without the noise of long articles.

The content covers system administration on Linux and Windows, containers with Docker and quick setups for common database servers. Each page focuses on one topic and goes straight to the commands and files you need.

## How to use it

Use the search bar or press ++s++ / ++slash++ to find a command quickly. Code blocks have a copy button in the top-right corner.

These notes are a work in progress and grow as I find new things worth keeping.
